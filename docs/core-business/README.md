# EU Core Business Vocabulary

Unofficial HTML rendering of the supplied core-business-ap.ttl, using the ReSpec publication style of GAM.

Published at https://jgmikael.github.io/docs/core-business/

The source contains 146 RDF triples: 4 classes and 10 properties. The original Turtle is retained unchanged; vocabulary.jsonld contains the same RDF graph.

Rebuild with Python 3: pip install rdflib==7.6.0 then python build.py.
