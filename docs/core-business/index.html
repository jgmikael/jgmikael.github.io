Abstract

This publication documents the EU Core Business Vocabulary terms contained in the supplied core-business-ap.ttl RDF file: 4 classes and 10 properties, covering accounting documents, administrative units, contact points, legal status, registration dates and powers of attorney.

This is an unofficial HTML rendering of the supplied RDF, published alongside GAM. It is not an official EU or W3C publication. The source identifies the ontology as core-business and records an issue date of 12 May 2026. No version identifier is asserted in the file.

The original definitions, domains, ranges and scope notes are preserved. External terms referenced by the RDF are linked but are not redefined here. This document covers the uploaded file rather than claiming to reproduce every term in the wider Core Business Vocabulary.

Class definitions

Accounting Document

http://data.europa.eu/m8g/AccountingDocument

Financial and non-financial information as a result of an activity of an organisation.

Typeowl:Class
Defined by<http://data.europa.eu/m8g>

Scope note

Accounting documents, might include:
  • Financial statements (incl. the list of participating interests, subsidiary undertakings and associated undertakings, their registered office address and proportion of capital held), audit reports.
  • Non-financial statements, management reports and other statements or reports.
  • Annual financial reports.

Administrative Unit

http://data.europa.eu/m8g/AdminUnit

A detailed administrative unit organized in a hierarchy.

Typeowl:Class
Defined by<http://data.europa.eu/m8g>

Scope note

This class should be used whenever a classification mechanism is in place, in alternative to the properties adminUnitL1 and adminUnitL2 of the Address class which allow free text.

Properties with this domain: <http://data.europa.eu/m8g/code>, <http://data.europa.eu/m8g/level>

Properties with this range: <http://data.europa.eu/m8g/adminUnit>

Contact Point

http://data.europa.eu/m8g/ContactPoint

Information (e.g. e-mail address, telephone number) of a person or department through which the user can get in touch with.

Typeowl:Class
Defined by<http://data.europa.eu/m8g>

Scope note

The Core Public Organization Vocabulary defines properties for telephone number, e-mail address and opening hours although it is noteworthy that the class is based on schema.org's ContactPoint class that has additional properties that some implementations may find useful.

Properties with this domain: <http://data.europa.eu/m8g/contactPage>, <http://data.europa.eu/m8g/email>, <http://data.europa.eu/m8g/telephone>
