# EBWV ownership/control extension

Editorial proposal: 29 new properties, 9 new classes and one ownershipPercentage revision.

Built using the EBWV vocab/src/template.html and the yml2vocab tool invoked by vocab/scripts/build.zsh. Upstream copies are retained in upstream/. The template is adapted for this draft, attribution and publication URL; unrelated EBWV diagrams are omitted.

Rebuild: install yml2vocab@1.11.0 into ../publishing-runtime, install PyYAML, rdflib and beautifulsoup4, then run python3 prepare_template.py and python3 run_publisher.py. build.py records the original proposal construction but is not needed for rebuilding the maintained YAML.

Publisher adaptation: external referenced classes are added as CURIE entries in publisher-source/vocabulary.yml, without redeclaring their axioms. range_union flags preserve alternatives. After publishing, beneficiaryClassDescription is narrowed back from the publisher's future-proof langString/dirLangString union to the agreed rdf:langString range. The context is generated by yml2vocab. Use explicit language-tagged JSON-LD value objects for language strings.

The generated context uses type-scoped terms: for ExpressTrust include both LegalArrangement and ExpressTrust in @type to activate the arrangement properties. Combine with the VC and published EBWV contexts when using existing terms.

ownershipPercentage is a replacement proposal. Do not load both its old and new range/domain definitions. Detailed condition profiles, controlled concept schemes and SHACL validation remain subsequent work.

Upstream source: webuild-consortium/wp4-semantics-group, vocab/. Generator: W3C yml2vocab 1.11.0.
